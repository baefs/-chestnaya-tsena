# Честная цена

Локальный frontend-прототип сервиса сравнения стоимости повседневных услуг в Москве.

## Запуск
1. Скачайте репозиторий.
2. Откройте терминал в корне проекта.
3. Выполните:
   `python -m http.server 8000`
4. Откройте http://localhost:8000

Также можно использовать Live Server в VS Code.

## Реализовано
- Адаптивная главная страница.
- Каталог стандартизированных услуг.
- Поиск услуг и фильтрация по категориям.
- Экран сравнения стоимости.
- Раздел аналитики.
- Раздел карты.
- Методология проверки цен.
- Русскоязычный интерфейс, шрифт Golos Text с поддержкой кириллицы.
- Пустые состояния вместо выдуманных цен, организаций и координат.

## Ограничения текущего MVP
Это frontend-only прототип. PostgreSQL, API, реальные организации и цены, серверная авторизация администратора и интеграция Яндекс Карт пока не подключены. На интерфейсе явно обозначен демонстрационный статус.

## Следующий этап
